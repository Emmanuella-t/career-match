# Career Match Landing Page Kit

This kit gives you a clean starter package for building a landing page inspired by the provided reference image.

## Included
- `index.html` — starter landing page
- `styles.css` — responsive styling
- `brand-tokens.css` — locked brand variables
- `landing-page-copy.md` — suggested website copy
- `wireframe.md` — page structure
- `cursor-build-prompt.txt` — implementation prompt for Cursor
- `assets/career-match-logo.png` — logo
- `assets/hero-robot-reference.png` — cropped hero robot image
- `assets/landing-page-reference.png` — full page reference image
